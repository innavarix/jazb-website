JAZB Framework website

Static multi-page site for jazbframework.org.

Pages:
- index.html
- framework.html
- architecture.html
- publications.html
- research.html
- insights.html
- about.html

The site uses a shared styles.css and two alternating background assets in assets/. Published JAZB DOCX files are in downloads/.

Deployment: copy the contents of this folder to the GitHub Pages repository root. CNAME is included for jazbframework.org.
