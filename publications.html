CURRENT PUBLICATION FAMILY

Seven phases.
One canonical architecture.

JAZB Framework v1.2 is the current authoritative publication family. The first six publications develop the enterprise governance architecture from foundational doctrine through Authority, external passage, resilience, implementation, and standards alignment. Phase VII consolidates the framework into the canonical normative Reference Specification. Version 1.2 preserves the human-sovereign Authority model of earlier releases while making enterprise decision rights, use-case governance, continuous governance assurance, material-change revalidation, accountable residual-risk ownership, third-party limitations, and implementation architecture explicit.
