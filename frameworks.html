Terms used on this page

Core Operation
The complete configuration, in which people carry out every consequential action.
XAA-Enabled Operation
The optional configuration that adds the XAA for specific, pre-enrolled transactions.
XAA
Executive AI Assistant. An AI AGENT authorized to carry out specific consequential tasks, within the limits the EDA permits. Present only in XAA-Enabled Operation.
EDA
Enterprise Domain Authority. The human sovereign root of a JAZB organization; every other Authority traces back to it.
VTT
Virtual Tabletop Exercise. A published exercise that tests a specific JAZB version against an adversarial scenario. The suffix names the version tested: VTT-004-v1.0 was tested against JAZB v1.0.
RELEASE.CORE.XAA
The AI framework’s version format: framework generation, then common Core revisions, then optional XAA revisions.
MAJOR.MINOR.REVISION
The Cybersecurity Framework’s version format. The Core and the AI Extension each keep their own.
