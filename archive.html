ARCHIVED RELEASE | VERSION 1.1 | SEPTEMBER 2026

JAZB Framework Version 1.1

JAZB Framework Version 1.1 is a superseded but preserved historical release of the Judiciary AI Zero-Trust Broker architecture. Version 1.1 retained the human-sovereign Authority model established in Version 1.0 while strengthening behavioral governance, execution integrity, evidence, enforcement coverage, and conformance semantics.

The release formalized continuous and context-sensitive Point Policy governance across Baseline and Elevated Authority, persistent Point state and authorized reset, method-aware Authority, effective-target and effective-destination validation, enforcement-path coverage, repeated-denial and Governance Escape correlation, cross-jurisdiction behavioral evidence, independently protected telemetry, and compensating controls for authorized high-risk activity.

Version 1.1 remains permanently citable for implementations, validation exercises, crosswalks, research, and historical analysis that reference that release. It was superseded by Version 1.2; Version 1.3 is the current JAZB specification.

ARCHIVED RELEASE | VERSION 1.0 | SEPTEMBER 2026

JAZB Framework Version 1.0

JAZB Framework Version 1.0 is the initial published release of the Judiciary AI Zero-Trust Broker architecture. It established the foundational human-sovereign model in which legitimate human Authority creates Law, AI operates within that Law, technical capability does not create Authority, and material governance actions remain traceable from their legitimate source through interpretation, execution, and evidence.

Version 1.0 established the seven-publication framework family and the core architectural concepts that remain recognizable in later JAZB releases, including Human-Established Law, the Enterprise Domain Authority, Governor, Judge, Commissioner, AGENT, separate Internal and Border Jurisdictions, Enterprise AI Customs, bounded delegation, independent Actuation Authority, Governance Escape Resistance, Chain of Authority, Chain of Evidence, and the Phase VII Reference Specification.

Version 1.0 remains an immutable historical release. Validation exercises, research, implementation evidence, and conformance statements performed against Version 1.0 remain historical results for the framework state that was actually evaluated and should continue to identify Version 1.0 explicitly.
